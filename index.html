ABOUT THE TECHNOPIANO

TechnoPiano is a programmable piano-style hardware board powered by the BBC micro.

It combines music, programming, sensors, lights, and hardware control in one device.

WHAT'S ON THE TECHNOPIANO?

PIANO KEYS

Touch-style keys labeled C, D, E, F, G, A, and B can be used as inputs for programs.

A key can trigger lights, pictures, messages, or other actions.

SOUND AND LIGHT

The board includes a buzzer for sound and RGB lighting controlled through programs.

BBC MICRO

The micro acts as the programmable controller. It includes:

  • 5x5 LED matrix
  • Two programmable buttons
  • Microphone
  • Touch-sensitive logo
  • Light sensing
  • Accelerometer for detecting movement
  • Magnetometer for detecting direction

WIRELESS COMMUNICATION

The micro supports radio and Bluetooth communication. Radio allows one TechnoPiano to send a programmed message to another wirelessly.

CONNECTING MORE HARDWARE

The TechnoPiano and micro provide connections for additional electronic components and modules.

INPUTSKeys • Buttons • Sensors
PROGRAMInstructions created with programming blocks
OUTPUTSSound • Lights • LED pictures • Wireless messages • Connected devices
